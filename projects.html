Two connected projects: a processor built in SystemVerilog, and a simulator built to run it.

SystemVerilog · Python · FPGA

16-bit pipelined CPU

A custom instruction set, assembler, and five-stage processor. Runs Fibonacci on a Tang Nano 9K, with the output on seven-segment displays.

Design & FPGA demo →

CUDA · C++ · Yosys

GPU logic simulator

A gate-level simulator for the CPU’s 20,170-gate netlist. A persistent CUDA kernel cut the 100,000-cycle run from 53.2 to 11.3 seconds.

Implementation & benchmarks →

From hardware to simulation

The CPU started as a way to learn pipelining, hazards, and FPGA implementation. Its synthesized netlist became the test circuit for the simulator—a way to compare CPU and GPU execution on the same design.

The write-ups include the architecture, debugging notes, and measurements behind each project.
